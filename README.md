# Barry Brooke HOA

A community website for the Barry Brooke HOA - built to give residents a central place for documents, board info, and announcements, and to move payments online.

**Live site:** https://barrybrookehoa.vercel.app

<img width="1695" height="1240" alt="image" src="https://github.com/user-attachments/assets/d74e5898-7bdf-4db0-8caa-3ec57ccfe5ee" />

## Featurees
- Landing page with community overview
- Document access (C&Rs, meeting notes, announcements)
- Board member bios
- Online payments via Autobooks

## Roadmap
- Community calendar
- News/updates portal
- Contact form

## Tech Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
